1. The TDD loop (the thing you're practicing)
Red → Green → Refactor, in tiny steps:

Red — write one test for one behavior you want, run it, watch it fail (it must fail for the right reason).
Green — write the simplest code that makes it pass. Don't over-engineer.
Refactor — clean up while the test stays green.
Repeat.

The skill isn't writing tests — it's writing them before the code, one small behavior at a time.
